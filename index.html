Langton's Ant Enhanced

A modular, extensible Langton's Ant simulation in Python

About

This project implements Langton's Ant, a classic cellular automaton that demonstrates simple rule-based behavior leading to complex emergent patterns. This version expands on the traditional simulation with customizable ant behaviors and dynamic tile transformations.

Features

  • Core Langton's Ant Rules — Standard movement rules based on tile states.
  • Plugin System — Drop .py files into plugin directories; subclasses of Ant or Tile auto-register automatically.
  • Custom Ant Types — Implement update(self, world) for unique movement and interaction logic.
  • Custom Tile Types — Implement get_direction(self) to control ant steering, including diagonal steps.
  • Config-Driven — Edit settings/dev-settings.json (Pydantic-validated) to adjust grid size, ant composition, tile resolution, FPS, and random seed.
  • Dynamic Module Loading — All .py files from plugin directories are imported automatically at startup.

Quick Start

uv run python main.py

Requires Python ≥3.13 and uv.

Architecture

  • core/ — Ant, Tile, World, Registry
  • gui/ — MainWindow (pygame loop), renderer.py
  • engine/ — autoload.py (dynamic module importer)
  • common/ — Vector2, HTMLColor, DirectionVector
  • config/ — Pydantic config models, settings loader

Adding Custom Entities

  1. Subclass Ant or Tile from core/.
  2. Implement the required abstract method.
  3. Save the file in assets/entity/ or mods/.
  4. Add its class name + count to ant_config.types in settings/dev-settings.json.
